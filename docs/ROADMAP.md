# FitRank Roadmap

## Current

- Working FitRank app structure
- Workout logging
- ELO and ranks
- Workout history and saved local progress
- Instrument Panel atmosphere/design

## Next

1. Build a larger searchable exercise library.
2. Improve the workout logger using the exercise library.
3. Add user accounts with Google Sign-In.
4. Add secure cloud storage so each user's progress is connected to their account.
5. Build the Muscle Map using workout data and muscle-specific ranks.
6. Build food logging with small ELO bonuses focused on consistency, protein sources, and food variety without punishing foods.
7. Make FitRank installable as a PWA and continue final app polish.

Privacy and security will be considered when accounts are added, including keeping each user's data private and providing control over their stored data.
